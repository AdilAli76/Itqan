### 2. Entitlement Deduction Scheduled Job
**Status**: Controller created, service not yet implemented
**Files to create**:
- `backend/KineticEnterprise.Api/Services/EntitlementDeductionService.cs`
- `backend/KineticEnterprise.Api/HostedServices/EntitlementDeductionHostedService.cs`

**Requirements**:
1. Query all active deduction schedules
2. Check if today is the deduction day
3. For each schedule:
   - Get all customers in category with active entitlements
   - Calculate actual amount (override or category default)
   - Skip if already deducted this month
   - Create wallet transaction (kind=entitlement_deduction)
4. Update LastProcessedDate on schedule
5. Log audit trail

**Key logic**:
```csharp
// Pseudo-code
var today = OrgClock.Today(organization);
var schedules = await db.EntitlementDeductionSchedules
    .Where(s => s.IsActive && s.DeductionDayOfMonth == today.Day)
    .ToListAsync();

foreach (var schedule in schedules) {
    var customers = await db.Customers
        .Where(c => c.CategoryId == schedule.CustomerCategoryId 
             && c.AccountModel == "entitlement"
             && c.EntitlementExpiresOn > today)
        .ToListAsync();
    
    // Create transactions for each customer
    foreach (var customer in customers) {
        var amount = customer.EntitlementOverride ?? schedule.DeductionAmount;
        var transaction = new CustomerWalletTransaction {
            CustomerId = customer.Id,
            Kind = "entitlement_deduction",
            Amount = amount,
            ...
        };
    }
    schedule.LastProcessedDate = today;
}
```
