## 🔧 TROUBLESHOOTING

### Database Migration Fails
```sql
-- Check if tables already exist
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_NAME IN ('customer_tags', 'entitlement_deduction_schedules', 'print_audit_logs');

-- Check foreign key references
SELECT * FROM INFORMATION_SCHEMA.REFERENTIAL_CONSTRAINTS 
WHERE CONSTRAINT_NAME LIKE '%customer_tags%';
```

### Print Toggle Not Visible
- Verify print_control_toggle.dart imported
- Check pos_screen.dart includes PrintControlToggle widget
- Rebuild Flutter: `flutter clean && flutter pub get`

### Deductions Not Running
- Check EntitlementDeductionHostedService registered in Program.cs
- Verify server time is correct (UTC)
- Check application logs for errors
- Verify database has schedule records

### Print Timeout Not Working
- Verify receipt_printer.dart has 30-second timeout
- Check print operations take longer than 30 seconds
- Test with actual printer if available
