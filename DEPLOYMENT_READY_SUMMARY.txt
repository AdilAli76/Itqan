🚀 DEPLOYMENT STEPS (On Your Windows Machine)

STEP 1: Pull Latest Code
────────────────────────
  cd C:\kinetic-erp
  git pull origin claude/comprehensive-features-1.6.6

STEP 2: Create Deployment Package
──────────────────────────────────
  .\build-v1.6.6.ps1

  Expected output:
  ✓ Backend compiled
  ✓ Frontend built
  ✓ Package created: kinetic_pkg_2026-09-08_1430.zip
  ✓ SHA256 hash verified
  ✓ Total package size: ~75 MB

STEP 3: Transfer Package to Server
───────────────────────────────────
  Copy-Item .\kinetic_pkg_*.zip \\YOUR-SERVER\c$\publish\

STEP 4: Deploy to Server
─────────────────────────
  On your server:
  cd C:\publish
  Expand-Archive kinetic_pkg_*.zip -DestinationPath .\extracted
  .\extracted\1.6.6\deploy-now.ps1 -Target production

STEP 5: Verify Deployment
──────────────────────────
  curl http://localhost/api/health

  ✓ API responds with 200 OK
  ✓ Database migration complete
  ✓ All features accessible
