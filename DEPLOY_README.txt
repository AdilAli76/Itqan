Itqan ERP - Web Deployment Scripts
سكريبتات نشر نسخة الويب
════════════════════════════════════════════════════════════════

📝 الملفات المتوفرة:
════════════════════════════════════════════════════════════════

1. deploy.bat
   - Script Batch بسيط وسهل الاستخدام
   - لا يحتاج متطلبات إضافية
   - يعمل على Windows القديم والجديد

2. deploy.ps1
   - Script PowerShell متقدم
   - واجهة أفضل وتفاصيل أكثر
   - يحتاج PowerShell 5.0+

════════════════════════════════════════════════════════════════
🚀 كيفية الاستخدام:
════════════════════════════════════════════════════════════════

الخطوة 1: انسخ ملف ZIP إلى C:\temp
   - ملف ZIP: ItqanERP-Web-v1.0.0.zip
   - الموقع: C:\temp\

الخطوة 2: اختر طريقة النشر

   ❌ الطريقة 1 (الأبسط): استخدم Batch Script
   
   1. انقر بزر الفأرة الأيمن على: deploy.bat
   2. اختر: "Run as administrator"
   3. اضغط: Yes
   4. انتظر انتهاء العملية
   
   ====================================
   
   ✅ الطريقة 2 (المتقدمة): استخدم PowerShell Script
   
   1. افتح PowerShell كمسؤول:
      Win + X → ثم اختر PowerShell
   
   2. انتقل للمجلد:
      cd C:\Users\F\Downloads\itqan_erp
   
   3. شغّل السكريبت:
      .\deploy.ps1
   
   أو اختياراً مع معاملات مخصصة:
      .\deploy.ps1 -SourceZip "C:\temp\ItqanERP-Web-v1.0.0.zip" `
                   -TargetDir "C:\kinetic"

🔍 استكشاف الأخطاء:
